# Security Audit — Botium Toys

## Overview

This project involved conducting an internal security audit of Botium
Toys based on a scenario provided by an IT manager.

The audit focused on reviewing the organization's existing security
controls and compliance practices and identifying areas that required
improvement.

## Audit Scope

The audit covered the organization's overall security program,
including:

- Employee equipment and devices
- Internal network
- Organizational systems
- Existing security controls
- Compliance practices
- Data retention and storage
- Legacy systems

## Audit Objectives

The objectives were to:

- Review existing security controls
- Assess compliance best practices
- Identify security gaps
- Determine areas of risk
- Recommend improvements to strengthen the organization's security posture

## Key Findings

The audit identified several areas requiring improvement, including:

- Least privilege was not implemented
- Separation of duties was not implemented
- Encryption was not being used for sensitive customer information
- No intrusion detection system (IDS) was in place
- No disaster recovery plan was in place
- Critical data was not backed up
- Password requirements needed improvement
- No centralized password management system was in place
- Legacy-system maintenance lacked a regular schedule

## Recommendations

Based on the audit, I recommended implementing controls including:

- Principle of least privilege
- Separation of duties
- Data encryption
- Disaster recovery planning
- Data backups
- Intrusion detection
- Password management
- Improved legacy-system management
- Proper asset classification

## Risk Assessment

The scenario assigned the organization a risk score of **8 out of 10**,
primarily due to gaps in security controls and compliance practices.
