# Incident Handler's Journal

## Overview

This journal documents a series of cybersecurity investigation and incident response activities completed during my cybersecurity training. The activities provided practical experience with identifying security incidents, analyzing network traffic, investigating indicators of compromise, and documenting incident findings.

## Activities Covered

- Ransomware incident investigation
- Phishing incident investigation
- Network traffic analysis with Wireshark
- Network packet capture and analysis with tcpdump
- Phishing incident response using a response playbook
- Network intrusion detection analysis with Suricata
- Incident and data breach report analysis
- Malicious file hash investigation using VirusTotal

## Tools Demonstrated

- Wireshark
- tcpdump
- Suricata
- VirusTotal
- jq
- Phishing Incident Response Playbook

## Skills Demonstrated

- Incident investigation
- Phishing analysis
- Network traffic analysis
- Packet capture and analysis
- Indicators of compromise (IOC) identification
- Intrusion detection
- Incident response and escalation
- Security documentation and reporting

## Key Takeaway

These activities strengthened my understanding of the incident detection and response lifecycle and gave me practical experience using cybersecurity tools to investigate security events. I also developed a stronger interest in network traffic analysis and continued learning about tools used to capture and analyze network activity.
