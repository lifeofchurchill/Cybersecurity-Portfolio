# Linux File Permissions and Authorization

## Overview

This activity focused on reviewing and modifying Linux file and directory permissions to ensure they matched the required level of authorization for users and groups.

## Tasks Completed

- Used `ls -la` to inspect file and directory permissions.
- Analyzed Linux permission strings for users, groups, and others.
- Removed unauthorized write access from `project_k.txt`.
- Updated permissions for the hidden `.project_x.txt` file.
- Restricted the `drafts` directory so that only the `researcher2` user retained execute access.
- Used `chmod` to modify permissions and `ls -la` to verify the changes.

## Skills Demonstrated

- Linux command-line
- File and directory permissions
- Access control and authorization
- `ls` and `chmod` commands
- Permission verification

## Key Takeaway

This activity strengthened my understanding of Linux file permissions and how appropriate access controls can help protect organizational files and directories from unauthorized access.
