# Apply Filters to SQL Queries

## Overview

This activity focused on using SQL filters to investigate potential security issues involving login attempts and employee machines. I worked with the `log_in_attempts` and `employees` tables to retrieve specific records based on security-related requirements.

## Tasks Completed

- Retrieved failed login attempts that occurred after 18:00.
- Retrieved login attempts from May 8 and May 9, 2022.
- Retrieved login attempts that occurred outside of Mexico.
- Retrieved employees in the Marketing department in the East building.
- Retrieved employees in the Finance or Sales departments.
- Retrieved employees who are not in the Information Technology department.

## SQL Concepts Demonstrated

- `WHERE`
- `AND`
- `OR`
- `NOT`
- `LIKE`
- `%` wildcard
- Filtering data from multiple tables

## Skills Demonstrated

- SQL querying
- Security data investigation
- Data filtering
- Identifying potentially suspicious login activity
- Retrieving employee information for security updates

## Key Takeaway

This activity strengthened my ability to use SQL filters to retrieve specific information from organizational datasets and support security investigations and system updates.
